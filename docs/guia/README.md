1. [Primeiros passos](primeiros-passos.md): rode a demonstração e abra a bancada.
2. [Conceitos](conceitos.md) e [Interpretando resultados](interpretando-resultados.md): 15 minutos que evitam o erro mais comum (tratar coocorrência como prova).
3. [Receitas de uso](receitas-de-uso.md): o cenário mais parecido com o seu.
4. [Configuração](configuracao.md): índice da Receita e chaves de API, quando você precisar de mais cobertura.
